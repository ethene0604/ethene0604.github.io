题解#

给定n种物品和一背包。物品i的重量是$w_i$，其价值为$v_i$，背包的容量为$C$。问应如何选择装入背包的物品，使得装入背包中物品的总价值最大？
0-1背包本质上要求的是：

$$max\sum_{i=1}^nv_ix_i$$

它限定：

$$ \begin{cases} \sum_{i=1}^nw_ix_i\leq C\\ x_i ∈\{0,1\},1\leq i\leq n \end{cases} $$

不妨设$m(i,j)$是背包容量为$j$，可选择物品为$i,i+1,…,n$时0-1背包问题的最优值。由0-1背包问题的最优子结构性质，可以建立计算$m(i,j)$的递归式如下。

$$ m(i,j)=\begin{cases} m(i+1,j) & 0\leq j\lt w_i \\ max\{m(i+1,j),m(i+1,j-w_i)+v_i\} & j\geq w_i \end{cases} $$

解读：如果背包剩余容量不足以装下第i个物品，那么$m(i,j)=m(i+1,j)$，如果可以装下，则取装与不装状态后的最大值。
关于边界条件，即可选物品只有一件：

$$ m(n,j)=\begin{cases} v_n &j\geq w_n\\ 0 &0\leq j\lt w_n \end{cases} $$

算法改进#

算法需要$O(nc)$计算时间。当背包容量$c$很大时，算法需要的计算时间较多。例如，当$c\gt2^n$时，算法需要$Ω(n2^n)$计算时间。
由$m(i,j)$的递归式容易证明，在一般情况下，对每一个确定的$i(1≤i≤n)$，函数$m(i,j)$是关于变量j的阶梯状单调不减函数。跳跃点是这一类函数的描述特征。在一般情况下，函数$m(i,j)$由其全部跳跃点唯一确定。
对每一个确定的$i(1≤i≤n)$，用一个表$p[i]$存储函数$m(i,j)$的全部跳跃点。表$p[i]$可根据计算$m(i,j)$的递归式来递归地由表$p[i+1]$计算，初始时$p[n+1]=\{(0,0)\}$

函数$m(i,j)$是由函数$m(i+1,j)$与函数$m(i+1,j-w_i)+vi$作max运算得到的。因此，函数$m(i,j)$的全部跳跃点包含于函数$m(i+1,j)$的跳跃点集$p[i+1]$与函数$m(i+1,j-w_i)+v_i$的跳跃点集$q[i+1]$的并集中。
易知，$(s,t)\in q[i+1]$当且仅当$w_i\leq s\leq c$且$(s-w_i,t-v_i)\in p[i+1]$。（解释：如果在$q[i+1]$中，首先说明在容量$s$下能放入$w_i$且容量合理，且$(s-w_i,t-v_i)$应当对应$m(i+1,j-w_i)$）。
因此，容易由$p[i+1]$确定跳跃点集$q[i+1]$如下：

$$q[i+1]=p[i+1]\oplus(w_i,v_i)=\{(j+w_i,m(i,j)+vi)|(j,m(i,j))\in p[i+1]\}$$

另一方面，设$(a,b)$和$(c,d)$是$p[i+1]\cup q[i+1]$中的2个跳跃点，则当$c\geq a且d\lt b$时，说明$(c,d)$容量更大却价值更低，这个点不会是最优解，称为受控点。$(c,d)$受控于$(a,b)$，从而$(c,d)$不是$p[i]$中的跳跃点。除受控跳跃点外，$p[i+1]\cup q[i+1]$中的其它跳跃点均为$p[i]$中的跳跃点。
由此可见，在递归地由表$p[i+1]$计算表$p[i]$时，可先由$p[i+1]$计算出$q[i+1]$，然后合并表$p[i+1]$和表$q[i+1]$，并清除其中的受控跳跃点得到表$p[i]$。
改进后算法复杂度为$O(min(nc,2^n))$

分割等和子集#

链接：416. 分割等和子集 - 力扣（LeetCode）
给你一个 只包含正整数 的 非空 数组 nums 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。
解题：首先排除数组和为奇数/数组元素个数为1的特殊情况，设数组和为total，则该问题可以转化为容量为total/2的0-1背包问题。

def canPartition(self, nums: List[int]) -> bool:
        n=len(nums)
        lsum=0
        for num in nums:#求总和
            lsum+=num
        if n==1:#长度为1
            return False
        elif lsum%2==1:#和为奇数
            return False

        #需要划分
        target=lsum//2
        dp=[[0]*(target+1) for _ in range(n)]
        for i in range(1,n):
            for j in range(0,target+1):
                if nums[i]>j:#放不下+考虑越界
                    dp[i][j]=dp[i-1][j]
                else:
                    dp[i][j]=max(dp[i-1][j],dp[i-1][j-nums[i]]+nums[i])
        if dp[n-1][target]==target:#容量为target的时候，总和也为target（装满）
            return True
        else:
            return False

最后一块石头的重量#

链接：1049. 最后一块石头的重量 II - 力扣（LeetCode）
有一堆石头，用整数数组 stones 表示。其中 stones[i] 表示第 i 块石头的重量。每一回合，从中选出任意两块石头，然后将它们一起粉碎。假设石头的重量分别为 x 和 y，且 x <= y。那么粉碎的可能结果如下：

  • 如果 x == y，那么两块石头都会被完全粉碎；
  • 如果 x != y，那么重量为 x 的石头将会完全粉碎，而重量为 y 的石头新重量为 y-x。
    最后，最多只会剩下一块 石头。返回此石头 最小的可能重量 。如果没有石头剩下，就返回 0

题解#

设所有的石头的重量和为sum，被减去的石头的重量为neg，则留下来的石头的重量为sum-neg，最后的结果为sum-neg-neg=sum-2*neg，在满足neg<=sum/2的情况下，求得neg的最大值，即转换为背包问题。
对于该问题，定义二维布尔数组dp，其中$dp[i+1][]$表示前i个石头能否凑出重量j，特别地，$dp[0][]$为不选任何石头的状态，因此除了$dp[0][0]$为真，其余$dp[0][]$全为假。
对于第i个石头，考虑凑出重量j:

  • 若$j\lt stones[i]$，则不能选第i个石头，此时有$dp[i+1][j]=dp[i][j]$
  • 若$j\geq stones[i]$，存在选或不选两种决策，不选时有$dp[i+1][j]=dp[i][j]$，选时需要考虑能否凑出重量$j-stones[i]$，即$dp[i+1][j]=dp[i][j-stones[i]]$。若二者均为假则为假，否则为真。

因此状态转移方程如下:

$$ dp[i+1][j]=\begin{cases} dp[i][j]&j\lt stones[i]\\ dp[i][j]\vee dp[i][j-stones[i]]&j\geq stones[i] \end{cases} $$

求出$dp[n][]$后，所有为真的$dp[n][]$中，最大的j即为neg能取到的最大值。代入sum-2*neg中即得到最后一块石头的最小重量。

class Solution:
    def lastStoneWeightII(self, stones: List[int]) -> int:
        n=len(stones)
        total=sum(stones)#重量总和
        max_neg=total//2 #neg最大
        #dp[i+1][j]表示前i个石头能否凑出重量j
        dp=[[False for _ in range(max_neg+1)]for _ in range(n+1)]
        dp[0][0]=True

        for i in range(0,n):
            for j in range(0,max_neg+1):
                if j<stones[i]:
                    dp[i+1][j]=dp[i][j]
                else:
                    dp[i+1][j]=dp[i][j] or dp[i][j-stones[i]]
        max_weight=0
        for k in range(0,max_neg+1):
            if dp[n][k]:
                max_weight=k

        return total-2*max_weight

改进：由于$dp[i+1][\ ]$只和$dp[i][\ ]$有关，则可以采用滚动数组的方式消减一个维度，须知：采用滚动数组的方式遍历，容量需要从大到小，不然对应的$dp[i][j-stones[i]]$会被覆盖为$dp[i+1][j-stones[i]]$

 def lastStoneWeightII(self, stones: List[int]) -> int:
        n=len(stones)
        total=sum(stones)#重量总和
        max_neg=total//2 #neg最大
        #dp[i+1][j]表示前i个石头能否凑出重量j→滚动数组
        dp=[False for _ in range(max_neg+1)]
        dp[0]=True

        for i in range(n):
            for j in range(max_neg,-1,-1):
                if j>=stones[i]:
                    tmp=dp[j]
                    dp[j]= dp[j-stones[i]] or tmp

        max_weight=0
        for k in range(0,max_neg+1):
            if dp[k]:
                max_weight=k

        return total-2*max_weight
