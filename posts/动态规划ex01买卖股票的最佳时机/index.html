初始题#

121. 买卖股票的最佳时机 - 力扣（LeetCode）
给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。
你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。
返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0

解法#

事先声明，分析每一天持有股票状态和与状态相关操作并写出的状态转移方程核心都是不变的。
股票买卖问题具有最优子结构性质，前几天的利润一定是当前状态下能最大获利的决策。
这道题限制只能交易一次，对于每一天，有持有股票和未持有两种状态，如果未持有，有两种情况，可能前一天也未持有，也可能前一天持有今天卖出；同理，如果持有，可能前一天也持有，也可能前一天未持有今天购入。据此写出状态转移方程：用$dp[i][0]$表示第i+1天未持有股票下获得的利润，$dp[i][1]$表示持有股票下获得的利润。

$$\begin{cases} dp[i][0]=max(dp[i-1][0],dp[i-1][1]+prices[i])\\ dp[i][1]=max(dp[i-1][1],-prices[i]) \end{cases} $$

def maxProfit(self, prices: List[int]) -> int:
        n=len(prices)
        profit=0
        dp=[[0]*2 for _ in range(n)]
        dp[0][0]=0
        dp[0][1]=-prices[0]
        # 状态0：当天未持股 状态1:当天持股
        for i in range (1,n):
            dp[i][1]=max(-prices[i],dp[i-1][1])
            dp[i][0]=max(dp[i-1][0],dp[i-1][1]+prices[i])
        return dp[n-1][0]

变式1：允许无限次交易#

122. 买卖股票的最佳时机 II - 力扣（LeetCode）
在每一天，你可以决定是否购买和/或出售股票。你在任何时候 最多 只能持有 一股 股票。然而，你可以在 同一天 多次买卖该股票，但要确保你持有的股票不超过一股。
和上一题大致相同，转移方程稍微修改一下就好。

$$\begin{cases} dp[i][0]=max(dp[i-1][0],dp[i-1][1]+prices[i])\\ dp[i][1]=max(dp[i-1][1],dp[i-1][0]-prices[i]) \end{cases} $$

由于可以交易多次，所以购入的时候持有利润不一定为0。

def maxProfit(self, prices: List[int]) -> int:
        n=len(prices)
        dp=[[0]*2 for _ in range(n)]
        # 未持有股票dp[i][0]=max(dp[i-1][0],dp[i-1][1]+prices[i])
        # 持有股票dp[i][1]=max(dp[i-1][1],dp[i-1][0]-prices[i])
        dp[0][0],dp[0][1]=0,-prices[0]#第一天
        for i in range (1,n):
            dp[i][0]=max(dp[i-1][0],dp[i-1][1]+prices[i])
            dp[i][1]=max(dp[i-1][1],dp[i-1][0]-prices[i])
        return dp[n-1][0]

def maxProfit(self, prices: List[int]) -> int:
        n=len(prices)
        dp=[[0]*5 for _ in range(n)]
        #dp[i][0]从未交易，目前手上未持有股票
        #dp[i][1]从未卖出，目前手上持有股票
        #dp[i][2]交易过一次，目前手上未持有股票
        #dp[i][3]交易过一次，目前手上持有股票
        #dp[i][4]交易过两次，目前手上未持有股票
        dp[0][0]=0
        dp[0][1]=-prices[0]
        dp[0][2]=dp[0][3]=dp[0][4]=float('-inf')
        for i in range(1,n):
            dp[i][0]=dp[i-1][0]
            dp[i][1]=max(dp[i-1][1],dp[i-1][0]-prices[i])
            dp[i][2]=max(dp[i-1][2],dp[i-1][1]+prices[i])
            dp[i][3]=max(dp[i-1][3],dp[i-1][2]-prices[i])
            dp[i][4]=max(dp[i-1][4],dp[i-1][3]+prices[i])
        return max(dp[n-1][0],dp[n-1][2],dp[n-1][4])

变式3：最多允许k次交易#

188. 买卖股票的最佳时机 IV - 力扣（LeetCode）
实际上就是变式2的从特殊到一般，根据已经交易的次数和当前有无持有股票一共有2k+1种状态，每个状态都与前一天的状态有关。

$$dp[i][j]=\begin{cases} max(dp[i-1][j],dp[i-1][j-1]+prices[i]) & i>0且i为偶数\\ max(dp[i-1][j],dp[i-1][j-1]-prices[i]) & i>0且i为奇数 \end{cases} $$

def maxProfit(self, k: int, prices: List[int]) -> int:
        n=len(prices)
        cases=2*k+1 #第i次/是否持有 共有这么多情况
        dp=[[0 for _ in range(cases)] for _ in range(n)]
        dp[0][0],dp[0][1]=0,-prices[0]
        for i in range(2,cases):
            dp[0][i]=float('-inf')#其余都为负无穷

        for i in range(1,n):
            for j in range(1,cases):
                if j%2==0:#说明交易了j//2次，未持有股票
                    dp[i][j]=max(dp[i-1][j],dp[i-1][j-1]+prices[i])
                else:
                    dp[i][j]=max(dp[i-1][j],dp[i-1][j-1]-prices[i])

        profit=float('-inf')
        for i in range(k+1):
            if dp[n-1][i*2]>profit:
                profit=dp[n-1][i*2]
        return profit

变式4：需要手续费#

714. 买卖股票的最佳时机含手续费 - 力扣（LeetCode）
你可以无限次地完成交易，但是你每笔交易都需要付手续费。如果你已经购买了一个股票，在卖出它之前你就不能再继续购买股票了。
这里的一笔交易指买入持有并卖出股票的整个过程，每笔交易你只需要为支付一次手续费。
对于卖出这一动作加上手续费即可。

def maxProfit(self, prices: List[int], fee: int) -> int:
        n=len(prices)
        dp=[[0]*2 for _ in range(n)]
        dp[0][0]=0
        dp[0][1]=-prices[0
        for i in range(1,n):
            #当前未持有股票：前一天未持有股票/前一天持有股票今天卖了+手续费
            dp[i][0]=max(dp[i-1][0],dp[i-1][1]+prices[i]-fee)
            #当前持有：前一天持有/前一天未持有今天购入
            dp[i][1]=max(dp[i-1][1],dp[i-1][0]-prices[i])
        return dp[n-1][0]
