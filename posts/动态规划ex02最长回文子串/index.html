题解#

链接：5. 最长回文子串 - 力扣（LeetCode）
如果子串只有一个字母，那必定为回文子串，所以思考$s[i:j]$为子串的条件为$s[i+1:j-1]$为子串且$s[i]==s[j]$。由此写出状态方程： $P(i,j)$代表子串$S_i...S_j$是否为回文串，取值为True或者False。 取False有两种情况：

  • $s(i:j)$本身不是一个回文串;
  • $i\gt j$，此时$s(i:j)$本身不合法。
    那么我们就可以写出动态规划的状态转移方程： $$P(i,j)=P(i+1,j-1)\&\&(Si==Sj)$$

class Solution: 
	def longestPalindrome(self, s: str) -> str: 
		n=len(s)# 字符串长度 
		dp=[[False for _ in range(n)]for _ in range(n)] 
		#dp[i][j]表示字符串[i,j]是否为回文串 
		start,end=0,0 
		#字符串长度为1为回文串 
		for i in range(0,n): 
			dp[i][i]=True 
		#字符串长度为2为回文串：字符相同即为回文串 
		for i in range(0,n-1): 
			if s[i]==s[i+1]: 
				dp[i][i+1]=True 
				start,end=i,i+1 
		
		for l in range(3,n+1): #dp的经典循环了，逐步扩大区间范围
			for i in range(0,n-l+1): 
				j=i+l-1 
				if s[i]==s[j] and dp[i+1][j-1]: 
					dp[i][j]=True 
					start,end=i,j 
					
		return s[start:end+1]

最长回文子序列#

链接：516. 最长回文子序列 - 力扣（LeetCode）

同样的分析思路：如果子串只有一个字母，那必定为回文子序列；如果有两个字母，也一定为子序列（这里和回文子串不太一样），这两个字母相同的话，回文子序列的长度扩展为2。

到一般的情形，如果$s[i:j]$为回文子序列，有三种情况：

  1. 回文子序列可以和$s[i+1,j]$一样
  2. 回文子序列可以和$s[i,j-1]$一样
  3. 若$s[i]==s[j]$，则回文子序列可以为$s[i+1,j-1]+2$

上述三种情况取最大值。

class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n=len(s)
        dp=[[1 for _ in range(n)]for _ in range(n)]#存区间范围内回文子序列的长度
        #回文子序列的长度至少为1
        #区间长度为2
        for i in range(n-1):
            if s[i]==s[i+1]:
                dp[i][i+1]=2

        #区间长度推广
        for l in range(3,n+1):
            for i in range(0,n-l+1):
                j=i+l-1
                if s[i]==s[j]:
                    dp[i][j]=max(dp[i+1][j-1]+2,dp[i+1][j],dp[i][j-1])
                else:
                    dp[i][j]=max(dp[i+1][j],dp[i][j-1])

        return dp[0][n-1]

编辑距离#

链接：72. 编辑距离 - 力扣（LeetCode） 给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数  。

你可以对一个单词进行如下三种操作：

  • 插入一个字符
  • 删除一个字符
  • 替换一个字符

典型的自底向上求解（虽然当时没有做出来是面向题解的）。用$dp[i][j]$存放$word1[:i]$变为$word2[:j]$所需要的操作数：

  1. 如果$word[:i]==word[:j]$：$dp[i][j]=dp[i-1][j-1]$
  2. 反之，有三种操作，取最小：$dp[i][j]=min(dp[i-1][j-1],dp[i-1][j],dp[i][j-1])+1$ 其中，$dp[i-1][j-1]$表示替换，$dp[i-1][j]$表示删除，$dp[i][j-1]$表示插入

特殊考虑$dp[0][i]$（一直增加）和$dp[i][0]$（一直删除）。

class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m=len(word1)
        n=len(word2)

        dp=[[0 for _ in range(n+1)]for _ in range(m+1)]
        #dp[i][j]:word1[:i]变为word2[:j]所需要的操作数

        #第一行：从空变为word2[:j]
        for i in range(n+1):
            dp[0][i]=i

        #第一列：从word1[:i]变为空
        for i in range(m+1):
            dp[i][0]=i

        #推广
        for i in range(1,m+1):
            for j in range(1,n+1):
                if word1[i-1]==word2[j-1]:
                    dp[i][j]=dp[i-1][j-1]

                else:
                    dp[i][j]=min(dp[i-1][j],dp[i-1][j-1],dp[i][j-1])+1

        return dp[m][n]

class Solution:
    def shortestPalindrome(self, s: str) -> str:
        t='#'+'#'.join(s)+'#'
        n=len(t)
        dp=[0]*n
        mx=idx=r=0
        
        for i in range(n):
            if mx>i:
                dp[i]=min(dp[idx*2-i],mx-i)

            else:
                dp[i]=1

            while i-dp[i]>=0 and i+dp[i]<n and t[i-dp[i]]==t[i+dp[i]]:
                dp[i]+=1

            if i+dp[i]>mx:
                mx=i+dp[i]
                idx=i

            if dp[i]==i+1:
                r=i+dp[i]-1

        return (t[:r:-1]+t).replace('#','')
