动态规划（Dynamic Programming）#

相比于分治将问题划分为互不相交的子问题，进行递归求解，再合并解，动态规划应用于子问题重叠的情况，即不同的子问题具有公共的子子问题。
动态规划算法对于每个公共子子问题只求解一次，将其解保存在一个表格中，从而避免重复计算。
动态规划方法通常用来求解最优化问题，通常用动态规划解决的问题具有最优子结构性质：一个问题的解，可以由他的子问题的解来确定，而要想达到当前状态的最优解，则子问题的解也应该是最优的，即全局最优解包含局部最优解。
同时具有重叠子问题性质：每次产生的子问题并不总是新问题，对每一个子问题只解一次，而后将其解保存在一个表格中，当再次需要解此子问题时，只是简单地用常数时间查看一下结果。
我们通常按如下4个步骤来设计一个动态规划算法:

  1. 刻画一个最优解的结构特征。
  2. 递归地定义最优解的值。
  3. 计算最优解的值，通常采用自底向上的方法。
  4. 利用计算出的信息构造一个最优解（可选）

矩阵连乘问题#

参考：《算法导论》CLRS p370
给定n个矩阵$\{A_1,A_2,...,A_n\}$ 其中$A_i$与$A_{i+1}$是可乘的，考察这n个矩阵的连乘积$A_1A_2...A_n$。由于矩阵乘法满足结合律，所以计算矩阵的连乘可以有许多不同的计算次序。这种计算次序可以用给矩阵加括号的方式来确定。
我们的目的是确定计算矩阵连乘积的计算次序，使得依此次序计算矩阵连乘积需要的数乘次数，即计算量最少。

穷举法
列出所有可能的计算次序并计算出相应需要的数乘次数，从中找到数乘次数最少的计算次序。
对于n个矩阵的连乘积，设其不同的计算次序为P(n)种。由于每种加括号方式都可以分解为两个子矩阵的加括号问题：$(A_1 ...A_k )(A_{k+1}…A_n )$可以得到关于P(n)的递推式如下：

$$P(n) = \begin{cases} 1 & n = 1 \\ \sum_{k=1}^{n-1}P(k)P(n-k) & n \gt 2 \end{cases}$$

由递推式可得$P(n)=\Omega(4^n/n^{3/2})$ 复杂度达到了指数级，显然非常糟糕

因此我们考虑用动态规划解决此问题，由反证法显然得出，这个问题具有最优子结构的性质。全局解为最优解必定包含子问题的最优解。
不妨将矩阵连乘积$A_iA_i+1...A_j$简记为$A[i:j]$，限制$i<=j$，假设这个计算次序在矩阵$A_k$和$A_{k+1}$之间断开，$i\leq k\lt j$，得到完全加括号方式为

$$(A_iA_{i+1}...A_k)(A_{k+1}A_{k+2}...A_j)$$

可得：

$$A[i:j]=A[i:k]+A[k+1:j]+分割的两个矩阵相乘计算量$$

接下来建立递归关系，记$A[i:j],1\leq i \leq j \leq n$所需要的最少数乘次数为$m[i,j]$，则所求为$m[1,n]$,用表$s[i,j]$记录$m[i,j]$对应的分割点$k$。
当$i=j$，则只包含了一个矩阵，不需要数乘，即$m[i,i]=0,i=1,2,...,n$ 当$i\lt j$，假设$A[i:j]$的最优方案分割点在$k$，则有

$$m[i,j]=m[i,k]+m[k+1,j]+分割的两个矩阵相乘计算量$$

由于矩阵$A_i$的大小为$p_{i-1}×p_i$，易知$A[i:k]$与$A[k+1:j]$相乘的代价为$p_{i-1}p_kp_j$次标量乘法运算。因此，我们得到：

$$m[i,j]=m[i,k]+m[k+1,j]+p_{i-1}p_kp_j$$

$k$只有$j一i$种可能的取值：$k=i,i+1,...j一1$。由于最优分割点必在其中，我们只需检查所有可能情况，找到最优者即可。因此：

$$m[i,j] = \begin{cases} 0 & i = j \\ min_{i\leq k \lt j}\{m[i,k]+m[k+1,j]+p_{i-1}p_kp_j\} & i \lt j \end{cases}$$

根据取i和j的情况，求得子问题的个数最多只有 $C_n^2+n=\Theta(n^2)$（找两个不同的数+两数相同）
用动态规划算法解此问题，在计算过程中，保存已解决的子问题答案。每个子问题只计算一次，而在后面需要时只要简单查一下，从而避免大量的重复计算，最终得到多项式时间的算法。

void MatrixChain(int *p，int n，int **m，int **s)
{
	for(i=1;i<=n;i++)
		m[i][i]=0 //只有一个矩阵 不需要数乘

	for(r=2;r<=n;r++){//区间长度不断扩大 算是dp的一个典型自底向上了
		for(i=1;i<=n-r+1,i++){
			j=i+r-1;
			m[i][j]=INT_MAX//初始情况置为无穷
			for(k=i;k<j;k++){
				q = m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j];
				//都是求得放入表格中的结果
				if (q < m[i][j]){//更新
					m[i][j] = q;
					s[i][j] = k;
				}
			}
		}
	}
}

最长公共子序列#

若给定序列$X=\{x1, x2,…, xm\}$，则另一序列$Z=\{z1, z2, …, zk\}$是X的子序列是指存在一个严格递增下标序列$\{i_1 , i_2 , …, i_k\}$使得对于所有$j=1,2,…,k$有$z_j = x_{i_j}$。
给定2个序列$X=\{x1 ,x2 ,…,xm\}$和$Y=\{y1 ,y2 ,…,yn\}$，找出X和Y的最长公共子序列。
这个问题具有最优子结构的性质：假设最长公共子序列为$Z=\{z_1,z_2,...,z_k\}$，从后向前推理，有：

  • 若$x_m = y_n$，则$z_k = x_m= y_n$，且$Z_{k-1}$是$X_{m-1}$和$Y_{n-1}$的最长公共子序列。
  • 若$x_m \neq y_n$ 且$z_k \neq x_m$，则$Z_k$是$X_{m-1}$和$Y_n$的最长公共子序列。
  • 若$x_m \neq y_n$ 且$z_k ≠ y_n$，则$Z_k$是$X_m$和$Y_{n-1}$的最长公共子序列。

因此，可以根据这三个情况建立递归关系，自底向上求解，用$c[i][j]$记录序列$Xi$和$Yj$的最长公共子序列的长度。其中，$Xi=\{x1,x2,…,xi\}$；$Yj=\{y1,y2,…,yj\}$。当$i=0或j=0$时，空序列是$Xi$和$Yj$的最长公共子序列。故此时$c[i][j]=0$。

$$ c[i][j]=\begin{cases} 0 & i=0\ or\ j=0\\ c[i-1][j-1]+1 & i,j\gt 0;x_i=y_j\\ max\{c[i][j-1],c[i-1][j]\} & i,j\gt 0;x_i \neq y_j \end{cases} $$

如果用一个矩阵来记录，可知$c[i][j]$与左侧、上方和左上方的值，因此，$c[i][0]=c[0][j]=0$，然后依次计算每一列。

class Solution: 
	def longestCommonSubsequence(self, text1: str, text2: str) -> int:
		m,n=len(text1),len(text2) 
		c=[[0]*(n+1) for _ in range (m+1)] 
		 for i in range (1,m+1): 
			 for j in range (1,n+1): 
				 if text1[i-1]==text2[j-1]: 
					 c[i][j]=c[i-1][j-1]+1 
				else: 
					c[i][j]=max(c[i][j-1],c[i-1][j]) 
		return c[m][n]

进一步优化：
数组元素$c[i][j]$的值仅由$c[i-1][j-1]$，$c[i-1][j]和c[i][j-1]$这3个数组元素的值所确定。
如果只需要计算最长公共子序列的长度，则算法的空间需求可大大减少。事实上，在计算$c[i][j]$时，只用到数组c的第i行和第i-1行。因此，用2行的数组空间就可以计算出最长公共子序列的长度。进一步的分析还可将空间需求减至$O(min(m,n))$。

凸多边形最优三角剖分#

用多边形顶点的逆时针序列表示凸多边形，即$P=\{v_0,v_1,…,v_{n-1}\}$表示具有n条边的凸多边形。
若$v_i$与$v_j$是多边形上不相邻的2个顶点，则线段$v_iv_j$称为多边形的一条弦。弦将多边形分割成2个多边形$\{v_i ,v_{i+1},…,v_j\}$和$\{v_j ,v_{j+1},…v_i\}$。 多边形的三角剖分是将多边形分割成互不相交的三角形的弦的集合T。 给定凸多边形P，以及定义在由多边形的三个顶点组成的三角形上的权函数$w(v_iv_kv_j)$。
要求确定该凸多边形的三角剖分，使得在该三角剖分中诸三角形上权之和为最小。 ![[al-3-1.png]] 凸多边形的最优三角剖分问题有最优子结构性质。
下面确定递归结构。
定义$t[i][j]$，$1≤i $t[i][j]$的值可以利用最优子结构性质递归地计算。当$j-i≥1$时，凸子多边形至少有3个顶点。由最优子结构性质，$t[i][j]$的值应为$t[i][k]$的值加上$t[k+1][j]$的值，再加上三角形$v_{i-1}v_kv_j$的权值，其中$i≤k≤j-1$。由于在计算时还不知道k的确切位置，而k的所有可能位置只有j-i个，因此可以在这j-i个位置中选出使$t[i][j]$值达到最小的位置。

$$ t[i][j]=\begin{cases} 0 & i=j\\ min_{i\leq k \lt j}\{t[i][k]+t[k+1][j]+w(v_{i-1}v_kv_j)\} & i\lt j \end{cases} $$

这道题和[[算法-CH3 动态规划#矩阵连乘问题]]有相似之处，都是需要一个分割点还有两个子部分的计算。

                            t[i][j]=temp
        return t[0][n-1]

多边形游戏#

多边形游戏是一个单人玩的游戏，开始时有一个由n个顶点构成的多边形。每个顶点被赋予一个整数值，每条边被赋予一个运算符“+”或“*”。所有边依次用整数从1到n编号。
游戏第1步，将一条边删除。
随后n-1步按以下方式操作：

  1. 选择一条边E以及由E连接着的2个顶点V1和V2
  2. 用一个新的顶点取代边E以及由E连接着的2个顶点V1和V2。将由顶点V1和V2的整数值通过边E上的运算得到的结果赋予新顶点。

最后，所有边都被删除，游戏结束。游戏的得分就是所剩顶点上的整数值。
对于给定的多边形，计算最高得分。 ![[al-3-2.png]]

设所给的多边形的边和顶点的顺时针序列为$op[1], v[1], op[2], v[2],op[3],…,op[n],v[n]$。 其中，$op[i]$表示第i条边所对应的运算符，$v[i]$表示第i个顶点上的数值，i=1~n。
在所给多边形中，从顶点i(1≤i≤n)开始，长度为j (链中有j个顶点)的顺时针链$p(i,j)$ 可表示为$v[i]，op[i+1]，…，v[i+j-1]$。则将一条边$op[i]$删去后，得到的链为$p(i,j)$。
如果这条链的最后一次合并运算在$op[i+s]$处发生(1≤s≤j-1)，则可在$op[i+s]$处将链分割为2个子链$p(i, s)$和$p(i+s,j-s)$。
这里的加法需要进行取模运算，即$mod n$。
下面考虑子链合并：
设$m1$是对子链$p(i,s)$的任意一种合并方式得到的值，而a和b分别是在所有可能的合并中得到的最小值和最大值。$m2$是$p(i+s,j-s)$的任意一种合并方式得到的值，而c和d分别是在所有可能的合并中得到的最小值和最大值。依此定义有$a≤m1≤b，c≤m2≤d$

  1. 当$op[i+s]='+'$时，显然有$a+c≤m≤b+d$
  2. 当$op[i+s]='*'$时，有$min\{ac，ad，bc，bd\}≤m≤max\{ac，ad，bc，bd\}$

换句话说，主链的最大值和最小值可由子链的最大值和最小值得到。
将$p(i, j)$在$op[i+s]$处断开的最大值记为$maxf(i, j, s)$，最小值记为$minf(i, j, s)$。

$$ minf(i,j,s)=\begin{cases} a+c & op[i+s]='+'\\ min\{ac，ad，bc，bd\}&op[i+s]='*' \end{cases} $$

$$ maxf(i,j,s)=\begin{cases} b+d & op[i+s]='+'\\ max\{ac，ad，bc，bd\}&op[i+s]='*' \end{cases} $$

由于最优断开位置s有1 ≤ s ≤ j-1的j-1中情况。

$$m[i,j,0]=min\{minf(i,j,s)\},1\leq i,j\leq n \ 1\leq s \leq j$$

$$m[i,j,1]=max\{maxf(i,j,s)\},1\leq i,j\leq n \ 1\leq s \leq j$$

初始边界值为 $m[i, 1, 0] = v[i]\ \ \ \ \ m[i, 1, 1] = v[i] \ \ \ \ 1 ≤ i ≤ n$
多边形是封闭的，当$i+s\gt n$时，顶点$i+s$实际编号为$(i+s)\%n$。$m[i,n,1]$记为游戏首次删除第i条边后得到的最大得分。

图像压缩问题#

在计算机中，常用像素点的灰度值序列$\{p_1 ,p_2 ,……p_n\}$表示图像。其中整数$p_i ,1<=i<=n$，表示像素点i的灰度值。通常灰度值的范围是0~255。因此最多需要8位表示一个像素。
图象的变位压缩存储格式将所给的像素点序列 $\{p_1 ,p_2 ,……p_n\}$，$0≤p_i≤255$分割成m个连续段$S_1 ,S_2 ,…,S_m$。
第i个像素段$S_i$中$(1≤i≤m)$，有$l[i]$个像素,且该段中每个像素都只用$b[i]$位表示。
分段的过程就是要找出断点，让一段里面的像素的最大灰度值比较小，那么这一段像素(本来需要8位)就可以用较少的位(比如7位)来表示，从而减少存储空间。
本题中， $0≤p_i≤255$，因此$b[i]\leq8$，即需要用3位表示$b[i]$，如果限制每段不超过255个像素，即$1\leq l[i]\leq255$，则需要用8位表示$l[i]$。因此，第i个像素段所需的存储空间为$l[i]*b[i]+8+3= l[i]*b[i]+11$位。（即：每个像素需要$b[i]$位表示，共有$l[i]$个像素，同时需要8+3位存储$l[i]和b[i]$。
按此格式存储像素序列$\{p_1 ,p_2 ,……p_n\}$，需要$\sum_{i=1}^{m}l[i]*b[i]+11m$位的存储空间。

设$l[i]，b[i]， 1≤i≤m$，是$\{p_1 ,p_2 ,……p_n\}$的最优分段。$l[1],b[1]$是$\{p_1 ,…,p_{l[1]}\}$的最优分段，且$l[i]，b[i]， 2≤i≤m$是$\{p_{l[1]+1},…,p_n\}$ 的最优分段。即图象压缩问题满足最优子结构性质。

设$s[i]，1≤i≤n$，是像素序列$\{p_1 ,…,p_i\}$的最优分段所需的存储位数，则$s[i]$为前i-k个的存储位数（已算过，是$s[i-k]$）加上后k个的存储位数（需再计算）。由最优子结构性质易知：

$$ s[i]=min_{1\leq k \leq min\{i,256\}}\{s[i-k]+k*bmax(i-k+1,i)\}+11 $$

其中$bmax(i,j)=\lceil log(max_{i\leq k \leq j}\{p_k\}+1)\rceil$为$p_i$到$p_j$中，最大的值需要的比特位数。

流水作业调度#

n个作业{1，2，…，n}要在由2台机器M1和M2组成的流水线上完成加工。每个作业加工的顺序都是先在M1上加工，然后在M2上加工。M1和M2加工作业i所需的时间分别为ai和bi。

流水作业调度问题要求确定这n个作业的最优加工顺序，使得从第一个作业在机器M1上开始加工，到最后一个作业在机器M2上加工完成所需的时间最少。

直观上，一个最优调度应使机器M1没有空闲时间，且机器M2的空闲时间最少，在一般情况下，机器M2上会有机器空闲和作业积压两种情况。

最优二叉搜索树#

参考《算法导论》CLRS p397

二叉搜索树
若它的左子树不空，则左子树上所有节点的值均小于它的根节点的值；
若它的右子树不空，则右子树上所有节点的值均大于它的根节点的值；
它的左、右子树也分别为二叉搜索树

对于已有序列和未在搜索树的值我们有关键字$k_1,…,k_n$和伪关键字$d_0,…,d_n$，它们分别有概率$p_i,q_i$，每个关键字是一个内部结点，而每个伪关键字是一个叶结点，我们有：

$$\sum_{i=1}^np_i+\sum_{i=0}^nq_i=1$$

我们希望对于一个序列的概率集合构造一棵期望搜索代价最小的二叉搜索树，称之为最优二叉搜索树，须知：最优二叉搜索树不一定是高度最矮的，概率最高的关键字也不一定出现在二叉搜索树的根结点。
由二叉搜索树树的性质，可知一棵二叉搜索树的任意子树必须包含连续关键字$k_i,...k_j,1\leq i\leq j \leq n$，其叶结点必定是伪关键字$d_{i-1},...,d_j$。
进一步的，认为最优二叉搜索树有最优子结构性质，如果子树并不是相应的最优二叉搜索树，那么替换后会找到一棵期望低于已有搜索树的树，这与已有最优的假设矛盾。
由最优子结构可以写出算法：
首先，在二叉搜索树T中搜索一次的期望代价为：

$$ \begin{align} E[T中搜索代价]&=\sum_{i=1}^{n}(depth_T(k_i)+1)p_i+\sum_{i=0}^{n}(depth_T(d_i)+1)q_i\\ &=1+\sum_{i=1}^{n}depth_T(k_i)p_i+\sum_{i=0}^{n}depth_T(d_i)q_i \end{align} $$

由上个公式（概率和为1）化简得出
设$e[i,j]$为在包含关键字$k_i,...,k_j$的最优二叉搜索树里进行一次搜索的期望代价，我们希望计算出$e[1,n]$。

  • 当$j=i-1$，子树不包含实际关键字，只包含伪关键字$d_{i-1}$，此时$e[i,j]=q_{i-1}$
  • 当$j\geq i$，我们需要从$k_i,...,k_j$选取一个根节点$k_r$，然后构建它的左子树$k_i,...k_{r-1}$，为最优二叉搜索树，同理右子树$k_{r+1},...,k_j$为最优二叉搜索树。 当一棵树成为一个结点的子树，每个结点的深度都增加了1，所以这棵子树的期望搜索代价的增加值应该为所有概率之和。设包含$k_i,...,k_j$的子树所有概率之和为： $$w(i,j)=\sum_{l=i}^jp_i+\sum_{l=i-1}^jq_i$$ 得到递归公式为： $$ e[i,j]=\begin{cases} q_{i-1}& j=i-1\\ min_{i\leq r \leq j}\{e[i,r-1]+e[r+1,j]+w(i,j)\} & i\leq j \end{cases} $$ 这道题同样和矩阵乘法非常相似。 链接：96. 不同的二叉搜索树 - 力扣（LeetCode）

def numTrees(self, n: int) -> int:
        dp=[[0]*(n+1) for _ in range(n+2)]#[1...n+1,0..n]
        for i in range (1,n+2):#只有伪节点
            dp[i][i-1]=1
        #所求为dp[1][n]
        for l in range (1,n+1):
            for i in range (1,n-l+2):
                j=i+l-1
                for r in range (i,j+1):
                    dp[i][j]+=dp[i][r-1]*dp[r+1][j]
        return dp[1][n]

戳气球#

链接：312. 戳气球 - 力扣（LeetCode）

用$coin[i][j]$表示戳气球区间为$(i,j)$获得金币，为开区间。

当区间只有一个气球，则$coin[i][i+2]=nums[i+1]$

当区间有两个气球，则较大的那个最后戳破。

按照这个规则，扩展区间。$maxcoins(n)=max(m[0:k]+m[k:n+1]+nums[k])$

class Solution {
public:
    int maxCoins(vector<int>& nums) {
        const int n = nums.size();
        // 长度扩充到了0到n+1,使用开区间
        nums.insert(nums.begin(), 1);
        nums.insert(nums.end(), 1);

        const int N = n + 2;
        // 用m[i:j]表示敲气球i与j之间的金币
        vector<vector<int>> coin(n + 2,vector<int>(n + 2,0));

        // maxcoins(n)=nums[0](n=1)区间内只有一个气球，只要敲一个
        // maxcoins(n)=max(m[0:k]+m[k:n+1]+nums[k])

        for (int i = 0; i < n; i++) {
            coin[i][i + 2] = nums[i + 1]; // 区间只有一个气球
        }

        for (int i = 0; i < n - 1; i++) {
            coin[i][i + 3] = max(nums[i + 1], nums[i + 2]) +
                             nums[i + 1] * nums[i + 2]; // 区间只有两个气球
        }


        for (int r = 3; r <= n + 2; r++) { // 区间越来越大
            for (int i = 0; i <= n + 2 - r; i++) {
                int j = i + r - 1;
                for (int k = i + 1; k < j; k++) {
                    int tmp =
                        coin[i][k] + coin[k][j] + nums[i] * nums[k] * nums[j];
                    if (coin[i][j] < tmp) {
                        coin[i][j] = tmp;
                    }
                }
            }
        }

        return coin[0][n + 1];
    }
};
